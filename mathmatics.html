Unit 1 — Matrices

A matrix is a rectangular arrangement of numbers, symbols or expressions in rows and columns.

Types of Matrices

  • Row Matrix
  • Column Matrix
  • Square Matrix
  • Zero Matrix
  • Identity Matrix
  • Diagonal Matrix
  • Symmetric Matrix

Unit 2 — Determinants

A determinant is a scalar value calculated from a square matrix.

For a 2 × 2 matrix:

|a b|
|c d|

Determinant = ad − bc

Unit 3 — Rank of Matrix

The rank of a matrix is the maximum number of linearly independent rows or columns of the matrix.

Methods

  • Echelon Form
  • Normal Form
  • Elementary Row Operations

Unit 4 — Eigen Values & Eigen Vectors

For a square matrix A, eigenvalues are obtained from:

|A − λI| = 0

Here λ represents an eigenvalue and I represents the identity matrix.

Unit 5 — Cramer's Rule

Cramer's Rule is a method for solving a system of linear equations using determinants.

Unit 6 — Permutation & Combination

Permutation deals with arrangements of objects, while combination deals with selections.

nPr = n! / (n-r)!

nCr = n! / [r!(n-r)!]

Unit 7 — Statistics

Statistics is concerned with collecting, organizing, analyzing and interpreting data.

  • Mean
  • Median
  • Mode
  • Variance
  • Standard Deviation
